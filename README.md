# real2sim

RealSense D435/D435i RGB-D → **SAM 3** instance masks → **SAM 3D Objects** per-object shape → **6-DoF pose**
(SAM 3D layout + ICP against the measured depth) → **OpenUSD / Isaac Sim** scene with each object as its own rigid body.
The RL (pick and place) side consumes the generated USDs or `real2sim.isaaclab_scene`.

```
RealSense ──► rgb.png + depth.npy (aligned to color, meters) + intrinsics.json
                │
                ├─ RANSAC table plane ──► world frame (z up, table top = z 0)
                ├─ SAM 3 (text prompts) ──► masks
                │      └─ per mask: SAM 3D Objects (image + mask + metric pointmap) ──► mesh + scale + pose
                │                     └─ ICP (visible mesh surface ↔ masked depth points) ──► refined 6-DoF
                └─ scene.json + objects/obj_XXX/mesh.ply + objects/obj_XXX/obj.usd + scene.usd
                                 │
            (env_isaaclab) build_isaac_scene.py ──► physics settling check / Isaac Sim GUI / RL
```

## Environments

| env | used for |
|---|---|
| `real2sim` (Python 3.11, torch 2.7.1 cu128, `usd-core`) | camera, SAM 3, SAM 3D Objects, 6-DoF pose, **standalone USD generation (`obj.usd` + `scene.usd`)** |
| `env_isaaclab` (optional; Isaac Sim 5.1 / Isaac Lab) | Isaac Sim GUI visualization, physics settling check (`--settle`), RL |

Supports both `x86_64` workstations (e.g., RTX PRO 6000 Blackwell) and `aarch64` edge devices (e.g., **NVIDIA Jetson Thor**).
`scripts/setup_env.sh` automatically detects the GPU compute capability, clones `third_party/` repositories, builds `pytorch3d` / `gsplat` from source for CUDA 12.8+, and installs `usd-core` so USD files are generated directly without requiring Isaac Sim on the capture/reconstruction machine.

```bash
bash scripts/setup_env.sh                 # once, ~20-40 min
bash scripts/download_checkpoints.sh      # prompts for HF token if not logged in
```

The checkpoints are gated. Request access first:
- https://huggingface.co/facebook/sam3
- https://huggingface.co/facebook/sam-3d-objects

## Usage

### 1. Capture + Reconstruct + Export USD (`real2sim` env — e.g. on Jetson Thor or Workstation)

```bash
conda activate real2sim && unset PYTHONPATH   # ~/.bashrc adds ROS Humble py3.10 paths that break py3.11
# 1) capture (or skip and use --capture in step 2)
python scripts/capture.py --out data/frames/test01
# 2) segment + reconstruct + pose + USD export (writes scene.json, objects/obj_XXX/obj.usd, scene.usd)
python scripts/run_pipeline.py --frame data/frames/test01 --out data/scenes/test01 --prompts cup bottle box
#    check: data/scenes/test01/segmentation.png, scene_cam.glb (meshes vs measured points in red)

# Re-export USD only (without running neural nets or Isaac Sim):
python scripts/build_isaac_scene.py --scene data/scenes/test01 --export-only
```

### 2. Physics Check & Visualization in Isaac Sim (`env_isaaclab` — on Workstation)

If you ran step 1 on another machine (such as Jetson Thor), copy the `data/scenes/test01` folder to the workstation (all USD references are relative) and run:

```bash
conda activate env_isaaclab
# Physics settling check (drift per object) using existing USD files
python scripts/build_isaac_scene.py --scene data/scenes/test01 --skip-export --headless --settle 240
# Open interactive GUI in Isaac Sim
python scripts/build_isaac_scene.py --scene data/scenes/test01 --skip-export
```

## Outputs (`data/scenes/<name>/`)

| file | content |
|---|---|
| `scene.json` | camera intrinsics, `T_world_cam`, table plane, per object: label, score, mesh path, `pose_cam`, `pose_world` (position, quat wxyz, rpy, 4x4), extents, ICP fitness/RMSE |
| `objects/obj_XXX/mesh.ply\|obj` | metric mesh in the object frame (SAM 3D canonical axes, origin at bbox center) |
| `objects/obj_XXX/obj.usd` | rigid body + mass + convex-decomposition collider + vertex-color material |
| `scene.usd` | table, dome light, RealSense camera at the real pose, all objects referenced at their poses |
| `settle_report.json` | how far each object moved under gravity: >2 cm means a bad pose or mesh |

## Tests

```bash
conda activate real2sim && unset PYTHONPATH && python tests/test_synthetic.py   # plane / ICP / world frame / USD export on rendered depth
conda activate env_isaaclab && python scripts/build_isaac_scene.py --scene data/scenes/synthetic --headless --settle 240 --drop_height 0.05  # drift ≈ 50 mm proves the check works
```

## Tuning

- `configs/default.yaml` `prompts`: SAM 3 needs concrete nouns (`cup`, `bottle`, `box`, `can`); the generic `object` returns nothing.
- `max_area_frac` drops large regions (table, wall); `on_plane_reject_frac` drops flat things on the table plane.
- `icp_min_fitness`: if ICP aligns fewer points than this, the SAM 3D pose is kept.
- The hidden back side of each object is generated by SAM 3D; scale comes from the metric pointmap.
